# Shubh Vivah — Claude Code build kit

Is folder mein wo sab hai jo Claude Code ko ek premium, animated Hindu wedding invite website
banane ke liye chahiye.

| File | Kiske liye | Kya hai |
|---|---|---|
| `CLAUDE.md` | Claude Code | Project ke rules, tech stack, kya karna hai / kya nahi |
| `SPEC.md` | Claude Code | Poora technical spec: data, API, har section, har animation ki timing, design system |
| `PHASES.md` | Tum + Claude Code | 8 phase, har ek ka copy-paste prompt aur "Done when" checklist |
| `ASSETS-AND-CONTENT.md` | Tum | Har asset free mein kahan se, license, AI prompts, premium look ke rules |
| `MANUAL-STEPS.md` | Tum | Google Sheet, Apps Script, Cloudflare, guests bhejna, testing |
| `content/wedding.json` | Dono | Saara text Hindi + English mein (sample). Asli details yahan bharo |

**Kaise shuru karein**
1. `MANUAL-STEPS.md` §1 karo.
2. Is folder mein Claude Code kholo.
3. `PHASES.md` se **Phase 1** ka prompt paste karo.
4. Har phase ke baad "Done when" check karo → commit → agla phase.
